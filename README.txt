# BK's unique fashion — AI Creative Studio

A free, responsive, bilingual (English + Sinhala) AI prompt library website.

## Included
- Premium dark modern design
- Sinhala / English language switch
- Search and category filters
- 12 editable AI prompt templates
- Prompt detail popup and copy button
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a modern browser. No build step or paid software is required.

## Publish free with GitHub + Vercel
1. Create a free account at https://github.com/
2. Create a new repository, e.g. `bks-unique-fashion`.
3. Upload `index.html` to the repository root and commit the change.
4. Create/sign in to https://vercel.com/ using GitHub.
5. Choose **Add New → Project**, import `bks-unique-fashion`.
6. For this static HTML site, leave Framework Preset as **Other**. No build command is needed. Set Output Directory to `.` if Vercel asks.
7. Click **Deploy**. Vercel will provide a public `*.vercel.app` address.
8. When you edit `index.html` and push changes to GitHub, Vercel redeploys automatically.

## Important
This starter is a prompt library, not an AI model/API. It does not generate images or videos itself. It provides reusable prompts to copy into AI services. Connecting real AI generation APIs may require API keys and can incur charges. Never put private API keys in front-end HTML/JavaScript.

## Customize
- Change the brand name in `index.html`.
- Add/edit prompt objects in the `data` array inside the script.
- Each prompt has English and Sinhala versions.
